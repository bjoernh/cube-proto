# cube-proto

Wire-protocol types (JSON requests, responses, events) and shared error types for the LED Cube 2.0 control plane.

Part of the [LED Cube 2.0](https://github.com/bjoernh/cube-proto) wire crates
(`cube-proto`, `cube-config`, `cube-presets`, `cube-admin-client`), shared by the
`cubed` daemon, its companion tools and the [`cubekit`](https://crates.io/crates/cubekit) app SDK.
